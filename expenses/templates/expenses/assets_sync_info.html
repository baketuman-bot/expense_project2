実行手順
  1. fpack が稼働している Windows 機にログインする。
  2. .batファイルの場所: deploy\windows_sync\sync_assets.bat （デスクトップにショートカットを作成済みならそちらから）をダブルクリックする。
  3. MDBファイルの保存場所: C:\fpack\FDATA001.MDB（ローカルディスクに配置。ネットワーク越しのパスには置かない）。
  4. 実行すると Push（Web側の変更をMDBへ送信）→ Pull（MDBの最新データをWebへ取込）の順に自動で行われる。 結果はコンソールと sync_assets.log に記録される。
  5. エラーになったキューを再送信する場合はコマンドプロンプトから python sync_assets.py --retry-errors を実行する。
  6. 書き込まずに内容だけ確認する場合は python sync_assets.py --dry-run を実行する。
  7. 同期中は fpack 側でデータを編集しない。処理を強制終了しない （MySQLとMDBの状態がズレるおそれがある）。
